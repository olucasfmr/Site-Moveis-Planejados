# Imagens do site

As imagens demonstrativas vêm do Unsplash e estão catalogadas em `lib/site-config.js`, na coleção `photos`. Para usar fotografias próprias, adicione os arquivos nesta pasta e substitua os endereços no arquivo de configuração por caminhos locais, por exemplo `/assets/img/cozinha.jpg`.

Os textos alternativos de cada imagem ficam junto de cada endereço no mesmo arquivo.
